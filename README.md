## 🎨 Interactive Sidebar Theme Switcher

Unlike standard static theme extensions, **Xeoo Theme** equips VS Code with a dedicated **Sidebar Theme Studio** in your Activity Bar:

- 🖱 **One-Click Theme Switching**: Browse all 26 themes grouped by aesthetic category and click any theme to apply it instantly.
- ⚡ **Quick Pick Palette (`Ctrl+Alt+T` / Title Icon)**: Fuzzy search all 26 palettes directly inside the Command Palette.
- 🎲 **Surprise Me!**: Click the sparkle icon in the sidebar title bar to pick a random theme when you want a fresh vibe.
- 🎯 **Active Indicator**: The sidebar automatically marks which theme is currently active with a checkmark badge.

## 🔬 Contrast & Ergonomic Analysis (UI/UX Engineering)

Every single theme in the **Xeoo Theme Suite** has undergone rigorous chromatic and contrast calibration:

### 1. Zero Eye-Strain Dark Foundation
- **No Stark Blinding Contrast**: Instead of pitch `#000000` with blinding pure `#ffffff`, we utilize deep obsidian charcoals (`#0a0e17` ~ `#18181b`) paired with soft crisp whites (`#e2e8f0` ~ `#f8fafc`).
- **Elimination of Retinal Fatigue**: Neon pure red (`#ff0000`) and electric lime (`#99ff00`) are replaced with spectral **Crimson Coral** (`#ff4d6d`), **Soft Emerald Mint** (`#4ade80`), and **Sky Blue** (`#60a5fa`).
- **WCAG AA Compliance (≥ 4.5:1 to 14:1)**: Numbers, booleans, and variables maintain high contrast and clarity.

### 2. Anti-Glare Light & Paper Foundation
- **No Blinding White Canvas**: Traditional light themes cause severe eye glare with 100% white (`#ffffff`). Xeoo Light themes use diffuse Japanese parchment and porcelain tones (`#f8f7f4`, `#faf6f7`, `#f4f6f9`).
- **Deep Sumi Ink Contrast**: Text is rendered in deep stone and mineral inks (`#1c1917`, `#0f172a`), delivering razor-sharp text legibility reminiscent of e-ink and luxury editorial print.
- **Jewel-Tone Syntax**: Keywords and functions use rich saturated jewel tones (Ruby, Sapphire, Pine, Walnut) that never wash out.

## 🏗 Modular Project Architecture

The extension is structured using a **Modular Design Token Engine** that generates all themes automatically:

```text
zx-theme/
├── package.json               # Extension manifest, sidebar views, commands & theme entries
├── assets/
│   ├── xeoo-logo.svg          # Vector brand logo with typography
│   ├── xeoo-icon.svg          # Square app icon for marketplace
│   └── activitybar-icon.svg   # Monochrome activity bar icon
├── src/
│   ├── extension.js           # Interactive sidebar TreeView & theme switcher
│   ├── build.js               # Automated compiler (npm run build / watch)
│   ├── tokens/
│   │   ├── palettes.js        # SSOT: Master definitions of all 26 palettes
│   │   └── ui.js              # Universal workbench UI generator (181 tokens)
│   └── syntax/
│       ├── textmate.js        # TextMate grammar token generator
│       └── semantic.js        # VS Code semantic highlighting (LSP)
└── themes/
    ├── xeoo-crimson-dark-color-theme.json
    ├── xeoo-midnight-ruby-color-theme.json
    └── ... (26 compiled JSON themes)
```

## 🛠 Developer & Contributor Guide

### 1. Build All Themes
```bash
npm run build
```
*Compiles all 26 themes from `src/tokens/palettes.js` into `themes/*.json` and synchronizes `package.json` in under 1 second.*

### 2. Live Watch Mode (Hot Reloading)
```bash
npm run watch
```
*Automatically rebuilds themes on save as you fine-tune colors.*

### 3. Test in VS Code (Extension Host)
1. Press `F5` in VS Code to launch the **Extension Development Host**.
2. Click the **Xeoo Theme** icon in the **Activity Bar** (Sidebar) to browse and switch themes with one click!

### 4. Package Extension (.vsix)
```bash
npm run package
```
